# COVID-19 Chest X-ray Classification with CNNs

A Keras notebook that trains convolutional neural networks to classify chest X-ray images, using `ImageDataGenerator` for loading and augmentation.

## Contents
- `COVID19-CLASSIFIER-DATAGENERATOR.ipynb`: data pipeline, CNN models and an experiment log. The log is a table comparing the number of Conv2D layers, epochs, batch size, input size, optimizer and learning rate against train, validation and test accuracy.

## Stack
Python · TensorFlow / Keras · Matplotlib

## Notes
Teaching and research notebook. The image dataset is not included in this repository.
